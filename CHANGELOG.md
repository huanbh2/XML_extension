# Change Log

## [1.0.0] - 2026-11-20
### Added
- Complete UI Card view: transforms raw XML tags into structured, readable cards and key-value tables.
- Interactive hierarchical tree viewer without angle brackets.
- Real-time search filter in toolbar.
- Expand all / Collapse all controls.
- Zero-CDN offline highlighting and styling.
- `Ctrl+Shift+V` keybinding and editor title bar preview icon.
- Auto-synchronization when switching between XML documents.
